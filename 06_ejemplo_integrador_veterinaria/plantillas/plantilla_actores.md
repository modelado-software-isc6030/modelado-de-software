# Actores del Sistema — Veterinaria

| Actor | Tipo | Descripción |
|---|---|---|
| Recepcionista | Principal | Registra turnos y datos de mascotas |
| Veterinario | Principal | Realiza consultas y diagnósticos |
| Cliente | Secundario | Solicita turnos y lleva mascotas |
| Administrador | Secundario | Gestiona información general del sistema |

---

# Justificación

## Recepcionista
Interactúa constantemente con el sistema para registrar mascotas, clientes y turnos.

## Veterinario
Utiliza el sistema para consultar historiales clínicos y registrar diagnósticos.

## Cliente
Solicita atención para sus mascotas y recibe información de turnos.

## Administrador
Administra información del sistema y supervisa registros generales.
