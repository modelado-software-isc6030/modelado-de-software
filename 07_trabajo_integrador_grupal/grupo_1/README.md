# 👥 Grupo 1 — Sistema Biblioteca

# 📖 Escenario

La biblioteca de un instituto realiza actualmente todos sus procesos de manera manual mediante planillas y cuadernos administrativos.

El personal bibliotecario necesita informatizar:
- préstamos de libros,
- devoluciones,
- reservas,
- multas,
- control de socios,
- y catálogo bibliográfico.

Actualmente existen problemas:
- pérdida de información,
- libros no devueltos,
- errores en multas,
- y dificultad para conocer disponibilidad de ejemplares.

El sistema deberá permitir administrar libros, autores, socios y préstamos.

---

# 📌 Roles involucrados

Dentro del sistema participan:

- Bibliotecario
- Socio
- Administrador

---

## Objetivo
Modelar el escenario utilizando UML.

---

## Actividad 1 — Identificación de Actores y Casos de Uso
- Identificar actores principales y secundarios.
- Identificar los casos de uso.
- Crear el diagrama UML.
- Explicar cada caso de uso brevemente.

---

## Actividad 2 — Identificación de Clases
- Detectar entidades principales.
- Identificar atributos y responsabilidades.
- Crear diagrama de clases.

---

## Actividad 3 — Diagrama de Secuencia
- Elegir un caso de uso principal.
- Modelar la interacción temporal entre objetos.

---

## Entrega
- Informe PDF o Word
- Diagramas exportados en PNG
- Explicación oral en clase

 # 🤝 Organización Recomendada del Grupo

Todos los integrantes deben participar del análisis y discusión del problema.

Se recomienda dividir:
- armado de diagramas,
- redacción,
- revisión,
- documentación,
- y carga al repositorio.

⚠️ No dividir el trabajo por “temas completos” (por ejemplo: una persona solo hace clases y otra solo secuencia), ya que todos deben comprender integralmente el modelado realizado.

Cada grupo deberá elegir un integrante responsable de:

- actualizar el repositorio,
- integrar los avances del grupo,
- realizar commits,
- y subir los cambios al repositorio remoto.

⚠️ Esto NO significa que una sola persona realice el trabajo.
Todos los integrantes deben participar del análisis, modelado y discusión de las soluciones.
